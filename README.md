# Neha Desai · Frontend engineering

Personal portfolio featuring Vue.js engineering, accessible interfaces, technical delivery and projects built in the open.

**Website:** https://neha-pd.github.io/portfolio-studio/

## Explore

- Professional case studies with clear employer/client attribution.
- Personal projects and early prototypes, with their current status and source links.
- Résumé download, GitHub projects and contact details.
- Responsive layout, keyboard-friendly disclosures and light/dark themes.

## Run locally

```sh
python3 -m http.server 8876 --bind 127.0.0.1
```

Open http://127.0.0.1:8876 . Static HTML, CSS and JavaScript; no build step or package installation.

## Assets and content

Project images are actual screenshots from Neha's public repositories and use fictional demo data. The portrait is AI-assisted, based on reference photos supplied by Neha's representative. Enterprise case studies contain summaries, not confidential client screens or code. Manrope is self-hosted under the included SIL Open Font License.

The site contains no analytics or contact-form backend. Theme preference is stored locally in the visitor's browser.

Published from this separate `neha-pd/portfolio-studio` repository, branch `main`, repository root. The earlier portfolios remain preserved in their existing repositories. Relative asset paths support project Pages hosting.

# Offscript

Working fashion capsule prototype by Neha Desai. WIP fictional concept, sample products/prices and AI-generated imagery. No real store or purchases.

Browse by category/search, inspect product details, choose a sample size, save to a browser-local edit, adjust quantity, remove items and download a text shortlist. Enquiry preview explicitly sends nothing. No backend, auth, real inventory, payments or personal information.

Source and design provenance: DESIGN.md. Buildless HTML/CSS/JS using shared local Manrope. Serve portfolio-studio on127.0.0.1:8796 and run scripts/native web/portfolio-studio/demos/boutique/qa/check.py from nightshift. Behavior/axe results and genuine screenshots live in qa/. Root owns publishing.

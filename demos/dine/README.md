# Juniper Table

Working fictional restaurant prototype by Neha Desai. WIP portfolio concept, no real business or bookings.

- Filter8sampledishes by category, vegetarian option and text; clear or inspect empty results.
- Pick a date, party1–6 and sample time; validates past/future limits and Monday closure.
- Preview details in a keyboard-accessible native dialog. No data is submitted, saved or charged.
- Responsive layouts, visible focus, reduced-motion support, no external runtime dependencies.
- Original AI-generated imagery; sources and design references in DESIGN.md.

Run a static server from portfolio-studio. Native QA: from nightshift run scripts/native web/portfolio-studio/demos/dine/qa/check.py, with portfolio-studio served at127.0.0.1:8796. Screenshots and results live in qa/. Parent agent owns publishing. No backend, authentication, live availability, allergen certification or payment support.

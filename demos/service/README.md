# Roomwork

Working fictional home-service prototype by Neha Desai. WIP concept, no real business, contractor credentials or client projects.

Choose a scope, floor area, room count, finish and extras. The model explains its fictional rates, displays a sample USD range, validates inputs and exports a browser-local project brief. No real quotation, site inspection, booking, contract, payment or provider message is made. Optional notes stay in memory and reset on reload; please omit personal details.

Buildless HTML/CSS/JS, shared local Manrope, original AI-generated interior photography. Responsive, accessible native controls, dark tokens, reduced motion. DESIGN.md contains reference and image provenance, calculation assumptions and limitations.

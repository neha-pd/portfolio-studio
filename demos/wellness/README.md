# Forma Rituals

Working fictional salon prototype by Neha Desai. WIP portfolio concept, no real business or appointments.

Interactive service selection, date picker/upcoming-day buttons, duration-aware simulated availability, live selection summary, validated appointment preview and FAQ. All state is browser-memory only. No PII or form submissions, backend, payment, real bookings, credentials or medical claims.

Buildless HTML/CSS/JavaScript with shared local Manrope font. Original AI-generated imagery; details in DESIGN.md. Responsive, visible focus, native dialog Escape, light/dark tokens and reduced motion.
